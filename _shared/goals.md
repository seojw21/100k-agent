## 성공 정의

### RateParse (8주 검증)
- **지속:** 유료 전환 **≥3건**
- **피벗 검토:** 3건 미만
- KPI: PayPal 라이브, 실 시트 샘플, trial 가입, $49, Reddit 9:1, GEO 주간 기록

### WhatReview (백업)
- B2 배포·PayPal·버티컬(인도 웨딩 포토) 런칭 준비만 캡 내에서
- **Kill:** 런칭 후 8주 유료 3건 미만 → 중단 후 RateParse 올인

### 회사 (12개월)
- [ ] 해외 달러 MRR 기반 (1차 **$1,000 MRR**)
- [ ] 검증된 제품 1개 이상 유료 고객 확보
- [ ] 로컬 LLM 운영비 ≈ 추가 API 0에 가깝게
