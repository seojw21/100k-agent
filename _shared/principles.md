## 1. 인건비 0 · 고정비 최소
- 사람 채용·사무실 가정 금지. 로컬 LLM + 에이전트가 손발.
- 고객 없으면 거의 $0 (RateParse solo kit 원칙).
- **클라우드 API 남발 금지.** 로컬 Ollama 우선.

## 2. 계산적 다작 (동시 분산 금지)
- 다작 = **순차**. 한 제품 8주 검증 후 다음 타자.
- **지금 1순위 RateParse**, 2순위 WhatReview(시간 캡).
- 신규 아이디어·pain_db 전수 탐색·유튜브 구독자 경쟁 **금지**.

## 3. 손절 기준이 있으면 실패도 성공
- RateParse: **8주 내 유료 3건 미만 → 피벗 검토** (후보군 다음: idea_975 등).
- WhatReview: 런칭 후 8주 유료 3건 미만 → 중단, RateParse 복귀.
- “무조건 성공” 금지. **싼 검증**이 목표.

## 4. 극니치 · 결과 판매
- 직군 × 문서/채널 × 작업 3중 니치 (GEO 강의).

- 엔터프라이즈 영업 콜 없는 self-serve ($49).
