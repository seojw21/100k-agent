# 구글 시트 두 탭 간 데이터 비교 및 변경사항 추적 자동화 도구
**카테고리:** AI_자동화
**점수:** 10
**태그:** #AI_자동화 #10점

## 😟 핵심 통증 (Pain Point)
구글 시트 내 두 개의 유사한 데이터 탭을 비교할 때마다, 어떤 데이터가 추가, 변경, 삭제되었는지 파악하기 위해 매번 복잡한 수식을 재작성해야 하는 번거로움이 있습니다. 이 과정은 시간이 많이 소요되고 오류 발생 가능성이 높습니다.

## 💡 해결 방안 (Solution)
사용자가 비교할 두 개의 시트와 기준이 되는 '키(key)' 열을 선택하면, 시스템이 자동으로 두 시트의 데이터를 비교 분석하여 ▲A시트에만 있는 데이터 ▲B시트에만 있는 데이터 ▲내용이 변경된 데이터 ▲완전히 일치하는 데이터를 구분하여 보여주는 구글 시트 애드온(Add-on)을 제공합니다. 분석 결과는 별도의 리포트 시트로 생성해주고, 변경 내용을 원본 시트에 병합(merge)하기 전 검토하고 적용할 수 있는 워크플로우를 제공합니다.

## 💰 수익화 근거 (Monetization)
수익화 근거: 사용자가 직접 유료 버전을 언급하며 지불 의사를 내비쳤습니다. 비교 횟수, 데이터 행(row) 수 제한을 두는 프리미엄(Freemium) 모델이 적합하며, 병합 전 검토 워크플로우나 데이터 내보내기 같은 고급 기능은 유료 플랜에 포함할 수 있습니다.
Web_Market_Search 결과 요약: "google sheets compare two sheets tool"로 검색한 결과, 'Ablebits Compare Sheets', 'Power Tools' 등 다수의 유사 기능을 제공하는 구글 시트 애드온이 존재합니다. 이는 해당 문제 해결에 대한 시장 수요가 분명히 존재하며, 경쟁이 이미 형성되어 있음을 의미합니다. UI/UX 편의성, 처리 속도, 대용량 데이터 처리 능력, 병합/리뷰 기능의 고도화를 통해 차별화가 필요합니다.
