# AI(Claude)가 PC 화면을 보고 GUI 앱을 직접 제어하는 로컬 서버
**카테고리:** AI_자동화
**점수:** 10
**태그:** #AI_자동화 #10점

## 😟 핵심 통증 (Pain Point)
Claude Code와 같은 AI 모델은 코드 생성은 잘하지만, 사용자의 PC 화면을 보거나 마우스/키보드를 조작할 수 없어 GUI 기반 앱(포토샵, 게임 등)을 자동화할 수 없다. 이로 인해 반복적인 GUI 작업을 AI에게 위임하지 못하고 사람이 직접 해야만 한다.

## 💡 해결 방안 (Solution)
사용자가 로컬에 설치하는 에이전트 프로그램을 제공한다. 이 에이전트는 백그라운드에서 실행되며, 클라우드 기반의 AI 모델(ChatGPT, Claude 등)로부터 API를 통해 명령을 받아 화면 인식(스크린샷, OCR), 마우스/키보드 제어, UI 요소 탐지 등의 작업을 수행한다. 사용자는 자연어로 "이 버튼을 찾아서 클릭해줘"와 같은 명령을 내릴 수 있으며, 별도의 복잡한 스크립트 작성 없이도 GUI 자동화가 가능하다.

## 💰 수익화 근거 (Monetization)
수익화 근거: 글쓴이가 직접 만든 솔루션의 Pro 버전을 19달러에 판매하고 있어 명확한 지불 의사가 확인된다.
검색 결과 요약: 시장에는 유사한 AI 에이전트 프로젝트(Open-Interpreter 등)나 전통적인 RPA 툴(UiPath)이 존재한다. 하지만 특정 AI 모델(Claude)에 최적화되고, 로컬 서버 방식으로 간편하게 설치할 수 있다는 점에서 차별점이 있다. 복잡한 설정 없이 자연어 기반으로 GUI 자동화를 원하는 개인 개발자나 소규모 팀을 대상으로 구독형(월/년) 또는 크레딧 기반 요금제를 도입할 수 있다.
