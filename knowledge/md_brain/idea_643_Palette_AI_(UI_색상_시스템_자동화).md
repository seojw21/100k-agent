# Palette AI (UI 색상 시스템 자동화)
**카테고리:** AI_자동화
**점수:** 9
**태그:** #AI_자동화 #9점

## 😟 핵심 통증 (Pain Point)
UI 디자인 시스템 구축 시 색상 선정 및 관리의 어려움 (주/보조 색상 지정, WCAG 명암비 준수, Tailwind/CSS 변수 변환 등 반복적인 수작업 및 고민).

## 💡 해결 방안 (Solution)
이미지 업로드만으로 AI가 주요 색상을 추출하고, UI 역할(primary, accent 등)을 매핑하며, WCAG 명암비 검사를 수행하고, Tailwind config 및 CSS 변수를 자동 생성해주는 웹 기반 SaaS.

## 💰 수익화 근거 (Monetization)
디자이너 및 개발자의 디자인 시스템 구축 시간을 획기적으로 단축하고, 색상 관련 휴먼 에러를 줄여 생산성을 높여줌. 고급 기능(팀 협업, 프로젝트 관리, 추가 프레임워크 지원 등) 및 사용량 기반으로 구독형 수익 모델 구축 가능.
