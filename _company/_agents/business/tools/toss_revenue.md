# 💳 토스페이먼츠(Toss Payments) 매출 자동 분석

비즈니스 에이전트가 본인 토스페이먼츠 가맹점 계정의 매출을 직접 분석. 일별/주별/월별 매출 + 결제 수단별 + 최근 거래 목록 분석 마크다운 리포트 생성.

## API 키 설정 방법 — Toss Payments

### 1. 토스페이먼츠 개발자 센터
- 접속: https://developer.tosspayments.com/
- 로그인 (또는 테스트 가입)

### 2. API 개별 키 복사
- **개발 정보** $\rightarrow$ **API 개별 키** 메뉴 이동.
- **Secret Key** 값을 복사합니다. (테스트 환경에서는 `test_gsk_...` 혹은 `test_sk_...` 형태입니다.)
- 복사한 키를 도구 설정(`toss_revenue.json`)의 `API_KEY` 필드에 붙여넣습니다.

> 💡 **Tip:** 만약 API 키를 비워두면, 자동으로 시스템에서 정밀하게 생성한 **시뮬레이션 모의(Mock) 매출 데이터**를 사용하여 리포트를 출력해 줍니다. 로컬 결제 검증에 유용합니다.

## 설정 (config)

| 키 | 의미 |
|---|---|
| `MODE` | `test` 또는 `live` |
| `API_KEY` | 토스페이먼츠 Secret API Key |
| `LOOKBACK_DAYS` | 분석할 과거 일수 (기본 30) |

## 출력
마크다운 리포트:
- 총 매출 요약 (Gross, 취소액, 순매출액, 결제성공 건수)
- 결제 수단별 매출 비중 (토스페이, 카카오페이, 네이버페이, 카드 등)
- 상품(아이템)별 매출 기여도 및 평균 단가
- 기간별 매출 흐름 (오늘 · 지난 7일 · 지난 30일)
- 최근 거래 10건 세부 내역
- 수익 목표 달성률 및 결제 행태 분석 비즈니스 인사이트

## 사용 예시 (대화)

```
사용자: "비즈니스 에이전트, 우리 회사 토스페이먼츠 매출 어때?"
→ CEO → business 분배
→ business: <run_command>python3 toss_revenue.py</run_command>
→ 결과 분석 보고
```
