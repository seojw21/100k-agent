NomadGuard AI의 핵심 가치는 '단순 절약'이 아니라 **'리스크 제거를 통한 심리적/재무적 안정성'**에 있습니다. 사용자가 리스크를 인지하는 순간 지불 의사(WTP)가 급격히 상승하므로, 가격 설계 역시 '공포-안심-최적화'의 심리 단계에 맞춰 배치했습니다.

단순한 가격표가 아니라, 실제 사용자의 지불 저항선을 측정하고 데이터 기반으로 최적가를 찾아내기 위한 **WTP 측정 프레임워크**를 제안합니다.

### 📊 NomadGuard AI: WTP 측정 기반 3단계 가격 시나리오

#### 1. 가격 체계 설계 (Pricing Ladder)
| 구분 | Trial (리스크 인지 단계) | Basic (안정성 확보 단계) | Premium (최적화 단계) |
| :--- | :--- | :--- | :--- |
| **포지셔닝** | "내 리스크는 얼마인가?" | "리스크를 통제하고 싶다" | "완벽한 최적화를 원한다" |
| **핵심 가치** | 1회성 리스크 진단 및 경고 | 실시간 규제 모니터링 + 기본 플래너 | 맞춤형 세무/법률 시뮬레이션 + 리포트 |
| **제안 가격** | **$0 (Free / 7일)** | **$19 ~ $29 / 월** | **$49 ~ $99 / 월 (또는 연결제)** |
| **WTP 측정 포인트** | 진단 후 '유료 기능' 클릭률 | 가격 저항선(Price Elasticity) 측정 | 고부가가치 서비스에 대한 지불 용의 |

---

#### 2. 단계별 핵심 KPI 및 전환 측정 지표
WTP를 정확히 측정하기 위해 단순 가입자가 아닌 **'행동 기반 전환 지표'**에 집중합니다.

**① Trial $\rightarrow$ Basic (전환율: Activation Rate)**
*   **핵심 KPI:** 진단 완료 후 Basic 플랜 결제 페이지 진입률
*   **측정 지표:** 
    *   `Risk-Awareness Rate`: 진단 결과에서 '위험' 판정을 받은 유저의 결제 시도 비율
    *   `Paywall Hit Count`: Basic 전용 기능(예: 실시간 알림) 클릭 횟수
    *   `Trial-to-Paid Conversion`: 무료 체험 종료 후 실제 결제 전환율

**② Basic $\rightarrow$ Premium (업셀링: Expansion Rate)**
*   **핵심 KPI:** 고급 시뮬레이션 기능 사용 요청률
*   **측정 지표:** 
    *   `Feature-Gap Request`: Basic 유저가 Premium 전용 '맞춤형 리포트'를 요청하는 빈도
    *   `Upsell Click-through Rate (CTR)`: 리스크 변동 발생 시 "Premium으로 정밀 분석하기" 버튼 클릭률
    *   `Average Revenue Per User (ARPU)`의 상승폭

**③ 전체 리텐션 및 LTV (Sustainability)**
*   **핵심 KPI:** 월간 반복 매출(MRR) 및 이탈률(Churn Rate)
*   **측정 지표:** 
    *   `Churn by Plan`: 어떤 가격대에서 이탈이 가장 심한가? (가격 저항선 확인)
    *   `LTV/CAC Ratio`: 고객 획득 비용 대비 생애 가치 (비즈니스 지속 가능성 판단)

---

#### 3. WTP 측정을 위한 구체적 실험 설계 (A/B Test)
단일 가격이 아닌 **'가격 밴드'**를 설정하여 최적점을 찾습니다.

*   **실험군 A (Low-Entry):** Basic $19 / Premium $49 $\rightarrow$ 볼륨 확대 및 시장 점유율 중심
*   **실험군 B (Mid-Value):** Basic $29 / Premium $79 $\rightarrow$ 수익성 및 가치 증명 중심
*   **실험군 C (High-End):** Basic $39 / Premium $129 $\rightarrow$ 고관여 타겟의 지불 한계 측정

# NomadGuard AI: WTP 측정 및 가격 시나리오 KPI

## 1. 가격 시나리오 (Pricing Ladder)
- **Trial ($0)**: 리스크 진단 및 경고 (인지 단계)
- **Basic ($19~$29/mo)**: 실시간 모니터링 및 기본 플래닝 (안정 단계)
- **Premium ($49~$99/mo)**: 맞춤형 시뮬레이션 및 정밀 리포트 (최적화 단계)

## 2. 전환 측정 지표 (Conversion Metrics)
### Trial $\rightarrow$ Basic
- **KPI**: Activation Rate (진단 후 결제 전환율)
- **핵심 지표**: 
  - 리스크 진단 완료 후 Paywall 도달률
  - Basic 전용 기능 클릭 횟수

### Basic $\rightarrow$ Premium
- **KPI**: Expansion Rate (업셀링 비율)
- **핵심 지표**: 
  - 맞춤형 리포트 요청 빈도
  - 정밀 분석 버튼 CTR

## 3. WTP 실험 설계 (A/B Testing)
- **Group A**: $19 / $49 (Volume focus)
- **Group B**: $29 / $79 (Value focus) - *Recommended*
- **Group C**: $39 / $129 (Premium focus)

## 4. 최종 의사결정 기준
- **전환율 > 5%**: 가격 유지 및 기능 고도화
- **전환율 < 2%**: 가격 하향 조정 또는 가치 제안(Value Prop) 재설계
