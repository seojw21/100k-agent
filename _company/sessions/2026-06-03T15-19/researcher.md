# 🎯 MVP 테스트용 타겟 페르소나 3 & WTP 검증 질문지

## 📌 배경 및 검증 목적
- **검증 대상:** 3040대 일상 업무/일상 프로세스 자동화 디지털 도구 (프롬프트 연동형 템플릿 서비스)
- **핵심 가설:** "학습 부담을 최소화한 직관적 UI + 복사-붙여넣기 즉시 완성"이 지불 의사(WTP)를 결정하는 주요 변수이다.
- **배포 전제:** 유튜브 입문 가이드 배포 전, 페르소나별 문제 공감도 및 가격 민감도를 정량화하여 프론트엔드 우선순위 및 가격 책정 선형(Price Ladder)을 확정한다.

---

## 👥 MVP 테스트용 타겟 페르소나 3가지

### 1. 효율성 추구형 직장인 (A페르소나)
- **기본 정보:** 30대 중반 | 대기업/중견 기업 주니어 매니저 | 월 업무 시간 대비 회의록·보고서 작성 비중 30% 이상
- **문제점 스토리라인:** 
  `"매주 금요일만 되면 정리되지 않은 회의 내용과 데이터 파싱에 2시간이 넘간다. 기존 템플릿은 항목이 너무 많아서 빈칸 채우기조차 번거롭고, AI 도구들은 프롬프트를 직접 맞춰야 해서 오히려 학습 부담이更大다."`
- **구매 동기:** 시간 절감 > 가격 민감도 낮음. `월 1~2만원` 대의 정기 구독이라도 "완전 자동화"라면 월 결제가 자연스러움.
- **기대 솔루션 UI/UX:** 드래그 앤 드롭 또는 버튼 클릭 1회로 구조 완성. 설정 화면 최소화.

### 2. 고민형 소규모 사업자 (B페르소나)
- **기본 정보:** 40대 초반 | 온라인 쇼핑몰/컨설팅 창립자 (1~3인 운영) | 마케팅 문구·계약서 초안·SNS 기획안 제작 빈도 주 5회 이상
- **문제점 스토리라인:** 
  `"매번 처음부터 문구를 짜다 보니 창작 소진(creative burnout)이 온다. 무료 AI는 결과물이 너무 일반적이고, 전문 대행사는 비싸서 중간 지점이 없다. '내 업계에 맞는 조금만 수정하면 되는 초안'이 필요하다."`
- **구매 동기:** 전문성 대용품 필요. `월 2~3만원` 또는 `일회성 14,800원` 대의 패키지에 높은 지불 의사 보임. 업계별 맞춤형 풀 제공 시 전환율 급증 예상.
- **기대 솔루션 UI/UX:** 산업별 탭 분리로 빠른 진입. 수정 가이드(주석) 포함. PC 최적화 필수.

### 3. 학습/재취업형 주부·프리랜서 (C페르소나)
- **기본 정보:** 30대 후반~40대 초반 | 경력 단절 후 재취업 준비 또는 홈베이스 비즈니스 운영 | 이력서·자기소개서·자격증 공부 자료 작성 빈도 높음
- **문제점 스토리라인:** 
  `"기능만 알려주는 강의는 이론이 많아 실제 작성으로 연결되지 않는다. 체크리스트와 예시가 동시에 필요한데, 기존 상품은 가격이 높거나 업데이트가 안 된다."`
- **구매 동기:** 결과물 완성도 확보 > 과정 학습. `일시불 9,900원~14,800원` 대 디지털 패키지에 높은 구매 전환 기대. 모바일 환경(카카오톡/네이버 연동) 접근성 중시.
- **기대 솔루션 UI/UX:** 단계별 진행 바(Progress bar) 제공. 모바일에서 바로 복사 가능. 오프라인 학습 연계 유도.

## 📊 지불 의사(WTP) 검증 질문지 5문항 (MVP 테스트용)

> ※ 배포 시 리드타임: 3분 내외 완료 권장 / 응답자 수: 50~100명 이상 통계적 유의성 확보 목표

| 문항 | 질문 내용 및 측정 방식 | 분석 포인트 (의사결정 기준) |
|:---:|:---|:---|
| **Q1** | 현재 `[본인의 주요 업무/일상]`에서 가장 번거로운 과정은 무엇이며, 그 과정에서 평균적으로 얼마나 많은 시간을 잃고 계신가요? <br>*(선지: 30분 미만 / 30분~1시간 / 1~2시간 / 2시간 이상)* | **문제 강도( Pain Intensity ) 측정**<br>1시간 이상 소모 응답 비중이 60% 초과 시 MVP 출시 타당성 확보 |
| **Q2** | 해당 문제를 해결하기 위해 기존에 어떤 방법(기타 도구, 무료 AI, 강의, 지인 도움 등)을 시도했으며, 그 결과물에 대한 만족도는 어느 정도였나요? <br>*(1~5점 리커트 척도)* | **대체재 가격/만족도 기준점 설정**<br>3점 이하일 경우 "차별화 포인트(학습부담 제로)" 강조 필요 |
| **Q3** | 다음 기능 중 가장 먼저 필요하다고 생각하는 것은 무엇이며, 이를 해결해 준다면 월 얼마까지 지불할 의사가 있으신가요? <br>*(직접 입력: ______원 미만 / 5,000~10,000원 / 10,001~20,000원 / 20,001원 이상)* | **핵심 가치 vs 가격 민감도 동시 측정**<br>최다 선택 기능은 MVP v1 스펙 확정. WTP 분포로 가격 띠(Price Band) 설정 |
| **Q4** | 일회성 구매(영구 사용권)와 정기 구독형 중 어떤 결제 형태를 선호하시며, 월 평균 지출 가능 한도는 얼마인가요? <br>*(선지: 일회성 1~2만원 / 월 5천원 미만 / 월 5천~1만 원 / 월 1만 원 초과)* | **비즈니스 모델 검증**<br>구독형 선호도 >70% 시 SaaS 구조 채택. 일회성 선호 시 디지털 패키지+추가 업데이트 판매 전략 전환 |
| **Q5** | 위 서비스가 '복사-붙여넣기만으로 완성'되지만, 초기 설정이 3분 소요된다면 이용을 고려하시겠습니까? <br>*(예 / 아니오 / 조건부: ~~하면 사용)* | **학습 부담 vs 편의성 트레이드오프 검증**<br>"아니오" 응답 비중이 높을 경우 UI 프론트엔드 개발 우선순위 재조정 (설정 화면 제거 또는 자동 생성 기능 추가) |

## 🛠️ 다음 단계 실행 가이드
1. **설문 배포:** 카카오톡 오픈채팅/브런치/유튜브 커뮤니티에 페르소나별 키워드 포함 링크 배치
2. **데이터 수집 후 분석:** Q3/WTP 분포를 히스토그램으로 시각화 → 평균치 ± 15% 구간을 `초기 가격 책정`으로 확정
3. **프론트엔드 우선순위:** Q1/Q5 결과에 따라 "설정 화면 최소화" 또는 "업계별 탭 강조" UI 반영
4. **콘텐츠 연계:** 설문 응답자 대상 유튜브 초보 가이드 배포 시, Q3에서 선택된 기능 위주로 데모 영상 제작
