🎨 Designer: 작업 시작합니다.

선정된 프로젝트 **'AI 기반 파편화 SaaS 통합 및 설정 템플릿 (The Integration Kit)'**에 대한 브랜드 비주얼 시스템과 랜딩 페이지 핵심 레이아웃 시안을 구상하여 제시합니다. 이는 신뢰 구축(Trust)과 자동화(Automation)라는 목표를 시각적으로 극대화하는 데 중점을 둡니다.

---

## 1. 브랜드 디자인 브리프 (Brand Design Brief)

이 시스템은 '복잡한 통합을 단순화하고, 설정 시간을 절약해주는 AI 기반 솔루션'이라는 핵심 가치를 전달하는 데 초점을 맞춥니다.

### 🎨 컬러 팔레트 (Color Palette)

신뢰감, 기술력, 차분함을 동시에 전달하는 블루 계열을 주조색으로 사용합니다.

| 역할 | 색상 이름 | HEX 코드 | RGB 값 | 용도 및 의미 |
| :--- | :--- | :--- | :--- | :--- |
| **Primary (신뢰)** | Deep Azure | `#1E3A8A` | (30, 58, 138) | 메인 헤드라인, 주요 버튼 등 핵심 신뢰 요소. 안정감 제공. |
| **Secondary (기술)** | Tech Teal | `#2DD4BF` | (45, 212, 191) | 강조 색상, 성공 메시지, 인터페이스 하이라이트. 혁신적이고 미래 지향적인 느낌 부여. |
| **Neutral (배경)** | Soft Gray | `#F8F9FA` | (248, 249, 250) | 전체 배경색. 깨끗하고 미니멀한 환경 제공. |
| **Accent (행동)** | Warm Gold | `#FBBF6B` | (251, 191, 107) | CTA(Call to Action) 버튼 및 중요 알림에 사용. 시선을 즉각적으로 유도. |

### ✒️ 타이포그래피 시스템 (Typography System)

가독성과 모던함을 동시에 확보하며, 기술적 전문성을 은은하게 드러냅니다.

| 역할 | 폰트 이름 | 스타일 | 용도 및 의미 |
| :--- | :--- | :--- | :--- |
| **Heading (제목)** | Inter | Bold / Semi-Bold | 명확하고 현대적인 제목 전달. 강력한 인상을 주면서도 읽기 편함. |
| **Body (본문)** | Roboto | Regular / Light | 복잡한 설정 텍스트와 설명에 사용. 높은 가독성을 보장. |
| **Code/Data** | Fira Code | Monospace | 통합 템플릿 코드 블록, API 명세 등 기술적 데이터 강조. 전문성 극대화. |

## 2. 랜딩 페이지 핵심 레이아웃 시안 (Landing Page Core Layout Sketch)

랜딩 페이지는 사용자가 **"이것이 내 문제를 해결해 줄 수 있는 가장 쉬운 방법이다"**라고 즉각적으로 인식하게 만드는 흐름(Flow)으로 설계합니다.

### 🏗️ 레이아웃 구조 및 섹션별 상세 지침

| # | 섹션 명 (Section Title) | 핵심 목적 (Goal) | 디자인 지침 (Visual Directives) | 사용 컬러/폰트 |
| :--- | :--- | :--- | :--- | :--- |
| **1** | **Hero Section (후킹)** | 문제 정의 및 솔루션 제시 (즉각적인 흥미 유발) | **헤드라인:** "SaaS 통합, 30분 만에 끝내세요." / **서브텍스트:** 복잡한 API 연동과 설정의 고통을 AI가 해결. / **CTA 버튼:** '무료 템플릿 받기' (Warm Gold 사용). 배경은 Soft Gray. | Primary, Accent |
| **2** | **Pain Point Validation (고통 공감)** | 잠재 고객의 현재 고통 지점 명확히 제시 | 3~4가지 핵심 문제(API 키 관리, 워크플로우 파편화, 수동 설정 등)를 아이콘과 간결한 문장으로 나열. | Neutral 배경에 Primary 텍스트 |
| **3** | **Solution Introduction (솔루션 소개)** | 'The Integration Kit'가 제공하는 가치 명시 | 솔루션의 핵심 기능(One-Click, Dynamic Generator, Validator)을 카드 형태로 시각화. 각 카드에 Tech Teal 색상으로 강조하여 기술적 우위를 표현. | Tech Teal 강조 |
| **4** | **How It Works (작동 방식)** | 자동화 과정의 단순성과 신뢰 구축 | 3단계 프로세스(Input -> Generate -> Validate)를 좌우 또는 상하 흐름도로 시각화. 각 단계는 명확한 아이콘과 짧은 설명으로 구성. | Primary 흐름선 사용 |
| **5** | **Template Showcase (템플릿 예시)** | 제품의 실제 결과물 시각화 및 신뢰 확보 | 실제 통합 템플릿 화면(Mockup)을 고화질 이미지로 제시. 'Before & After' 구도를 활용하여 시간 절약 효과를 극대화. | Soft Gray 배경, Mockup 강조 |
| **6** | **Pricing / CTA (구매 유도)** | 명확한 가격 제안 및 최종 행동 촉구 | Tier별(Starter, Business) 구조로 제시. 가장 강력한 옵션(Business Kit)을 Primary 색상으로 강조하고, 무료 체험/데모 버튼을 Warm Gold로 배치. | Primary & Accent 집중 |
| **7** | **Trust & Authority (신뢰 구축)** | 사회적 증거 및 보증 제공 | 사용 후기(Testimonials) 또는 기술 스택 로고(Stripe, Notion 등 연동 표시)를 배치하여 신뢰도를 높임. | Neutral 배경 |

### 💡 디자인 전략 요약

1.  **미니멀리즘 기반의 전문성:** 불필요한 장식을 배제하고, **Deep Azure**와 **Soft Gray**의 조합으로 전문가적이고 안정적인 느낌을 구축합니다.
2.  **기술적 강조:** **Tech Teal**은 혁신적인 AI 기능과 자동화 프로세스를 시각적으로 분리하여 '우리가 단순한 템플릿 판매자가 아니라, 지능적인 시스템 제공자'임을 어필합니다.
3.  **행동 유도:** 모든 CTA는 따뜻한 **Warm Gold**로 처리하여 사용자의 결정을 부드럽게 이끌어내고 구매 욕구를 자극합니다.
