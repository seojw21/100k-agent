### 1. 자동 산출 모델 설계
이미지의 시각적 복잡도를 3단계로 정규화하고, 각 단계별 작업 인원과 고정 단가를 매핑하여 고객이 이미지를 올리는 즉시 **[예상 비용 = 패키지 기본가 + (난이도 가변비)]** 구조를 자동 산출합니다.

| 난이도 | 이미지 특성 (매핑 기준) | 권장 작업 인원 | 고정 패키지 단가 (KRW) |
| :--- | :--- | :---: | :--- |
| **Level 1 (Easy)** | 단순 평면, 넓은 면적, 깨끗한 마감 상태 | 1명 | **490,000원** |
| **Level 2 (Medium)** | 부분적 변색/스크래치, 평균적인 시공 범위 | 2명 | **790,000원** |
| **Level 3 (Hard)** | 심한 오염·부식, 복잡한 구조(코너/프레임), 대규모 면적 | 3~4명 | **1,290,000원** |

### 2. 핵심 산출 수식 (Scoring & Pricing Engine)
시스템에 구현할 자동화 로직의 수학적 정의입니다:

- **난이도 점수 ($S$):** 이미지 분석 결과 기반 $S \in \{1, 2, 3\}$
- **작업 인원 ($W$):** $\text{if } S=1 \rightarrow W=1; \text{ if } S=2 \rightarrow W=2; \text{ else } W=4$ (Level 3는 변수 대응 위해 최대치 설정)
- **산출 비용 ($C$):** $C = P_S + (W \times B)$
  - $P_S$: 난이도별 고정 패키지 단가 (`[49, 79, 129]` 중 선택)
  - $B$: 작업자당 기본 비용 (**320,000원**)

**예시:** Level 2 이미지 수신 시 $\rightarrow$ **79만원 + (2명 × 32만원)**로 자동 산출.
