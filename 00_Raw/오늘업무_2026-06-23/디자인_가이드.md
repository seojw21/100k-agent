# 🎨 리퍼코퍼레이션 (Recovery Corp) 브랜드 비주얼 가이드 & 썸네일 컨셉

**작성일:** 2026-06-23  
**작성자:** Designer (Lead Designer)  
**참고:** 현빈의 `사업전략.md` 기반 (UK 기업정보 SaaS, 0→첫 거래 전환기, Tiered Subscription/Credit 모델)

## 1. 🎨 시각 아이덴티티 (Visual Identity)

### 색상 팔레트 (Color Palette)
B2B 데이터/SaaS 신뢰감 + YouTube 고대비 클릭 유도 원칙 적용

| 역할 | 색상명 | Hex 코드 | 사용처 |
|------|--------|----------|--------|
| **Base** | Deep Navy | `#0A192F` | 배경, 헤더, 신뢰감 강조 영역 |
| **Primary** | Electric Blue | `#00E5FF` | 로고, 핵심 버튼, 데이터 시각화 |
| **Accent** | Alert Gold | `#FFD700` | CTA, 숫자 강조, '절대 놓치지 말아야 할 가치' 표시 |
| **Warning** | Conversion Red | `#FF3B30` | 손실 금액 경고, 한정 혜택 카운트다운 |
| **Text** | Pure White | `#FFFFFF` / `#E6F1FF` | 본문, 서브 타이포그래피 |

> 💡 **디자인 원칙:** 배경은 `#0A192F` 또는 검정(`#000000`) 고정. 텍스트와 숫자는 고대비(흰색/노란색)로 처리하여 모바일 썸네일에서도 3초 내 가독성 확보.

### 타이포그래피 (Typography)
데이터 밀집도 높은 서비스이므로 **가독성**과 **숫자 정렬**을 최우선

- **주체 폰트:** `Inter` 또는 `Roboto` (San-serif, 기하학적 구조)
- **숫자/통계:** `JetBrains Mono` 또는 `Roboto Mono` (데이터 표기용 모노스페이스)
- **레이아웃 규칙:** 
  - 핵심 숫자(가격, 시간, 건수)는 본문보다 **2.5배 크게** 배치
  - 서브 카피는 `#E6F1FF` (연한 청백색)로 계층화
  - 줄간격(Leading): 1.4~1.6으로 데이터 가독성 최적화

## 2. 📺 YouTube Shorts 썸네일 3안 컨셉

현빈의 전략(첫 거래 0→突破, 크레딧제 병행, API 자동화)에 매칭되는 3가지 시각적 훅

### ✅ 컨셉 1: "잠긴 자산, 3초 만에 해제" (문제-해결 구조)
- **후크 문구:** `£0 → £5,000?` (또는 `$100/day lost`)
- **비주얼:** 
  - 좌측: 회색 톤의 복잡한 영국 기업 등기부 문서 이미지 (반투명 오버레이)
  - 우측: 선명한 `#00E5FF` 네온 글로우로 하이라이트된 PDF/CSV 아이콘
  - 중앙: `#FFD700` 굵은 화살표(→)로 시각적 이동 강조
- **텍스트 오버레이:** `영국 기업 정보, 이제 1클릭` (하단)
- **심리 트리거:** '손실 회복(Lost Income)'과 '즉각적 해결' 강조. 현빈의 첫 거래 인센티브 캠페인과 연동 가능

### ✅ 컨셉 2: "개발자도 반한 자동화" (기술/확장성 강조)
- **후크 문구:** `API 연동 완료` / `무제한 다운로드`
- **비주얼:** 
  - 검정(`#000`) 배경에 `#0A192F` 그라데이션
  - 중앙: 코드 블록 스타일의 JSON/API 응답 예시 (모노스페이스 폰트)
  - 하단: `#FFD700` 체크리스트 박스 (✅ 무제한 ✅ CSV 내보내기 ✅ 24/7 API)
- **텍스트 오버레이:** `월 $19부터 시작` (우측 상단, 가격 민감도 해소)
- **심리 트리거:** B2B 타겟(개발자/중견기업)의 '확장성'과 '저렴한 진입 장벽' 동시에 공략. Tiered Subscription 전략 시각화

### ✅ 컨셉 3: "크레딧제 체험" (저장벽 진입 유도)
- **후크 문구:** `10건 $9` / `첫 5건 무료`
- **비주얼:** 
  - 중앙에 크고 굵은 `#FFD700` 가격 태그(쿠폰 스타일)
  - 배경: 흐릿해진 영국 지도 실루엣 + 데이터 포인트 마커 (위치 기반 신뢰감)
  - 우측 하단: `PayPal` 로고 + `Instant Access` 배지
- **텍스트 오버레이:** `구독 부담 0원` (상단)
- **심리 트리거:** 현빈의 '크레딧제 병행' 전략 직접 반영. 구독에 대한 심리적 장벽을 낮추고 일회성 결제 유도

## 3. 📐 적용 체크리스트 (Design Review)
- [ ] 모든 썸네일 배경: `#0A192F` 또는 `#000000` 고정 (고대비 원칙)
- [ ] 핵심 숫자/가격: `#FFD700` 또는 `#FFFFFF` 볼드 (모바일 150% 확대 시 가독성 확인)
- [ ] 로고 워터마크: 우측 하단 10% 영역에 반투명(`opacity: 0.6`) 배치
- [ ] CTA 버튼/배지: `#FF3B30` (경고/긴급) 또는 `#00E5FF` (기술/신뢰)로 색상 의미 분리
- [ ] 폰트 가중치: 본문 `Regular(400)`, 제목/숫자 `Bold(700)` 이상만 사용 (시각적 혼잡 방지)
