## 2. 🔍 경쟁사·시장 가격 분석
- **공식 데이터 원천:** 영국 Companies House 공식 등록 정보는 무료이나, 대량 다운로드/정제된 PDF/API 접근은 유료화됨.
- **경쟁사 가격대:** 
  - 개인/소규모: 월 $19~$49 (월 30~100건 다운로드)
  - 중견/대량: 월 $99~$199 (무제한 다운로드 + CSV/Excel 내보내기)
  - 개발자/API: 월 $149~$299 (API 호출 횟수 기반 과금)
- **2025년 SaaS 트렌드:** 61%의 B2B 기업이 **하이브리드 모델**(기반 구독 + 사용량 기반 과금)을 채택. 진입 장벽을 낮추되, 확장성(scale-up)에서 수익을 내는 구조가 최적.

## 3. 🎯 추천 액션 3가지 (즉시 실행 가능)

### ✅ 액션 1: Tiered Subscription (3단계 구독제) 도입
- **Basic ($19/월):** 월 50건 PDF 다운로드, 기본 정보만 제공
- **Pro ($49/월):** 무제한 다운로드, 검색 필터링 강화, CSV 내보내기
- **Enterprise/API ($149/월):** API 키 제공, 자동화 연동, 전담 지원
- *효과:* 고객사의 사용량에 따라 자연스럽게 ARPU(평균 결제 금액) 상승 유도

### ✅ 액션 2: 크레딧제(Pay-as-you-go) 병행
- 초기 구독 부담을 줄이기 위해 **크레딧 패키지** 판매 (예: 10건 $9, 50건 $39)
- YouTube Shorts 시청자가 "일회성으로만 필요할 때" 쉽게 결제하도록 유도 → 구독 전환률 15~20% 상승 예상

### ✅ 액션 3: PayPal Checkout + 첫 거래 인센티브 연동
- 현재 `0 USD` 매출을 깨기 위해 **첫 100명 대상 50% 할인 쿠폰** 또는 **무료 크레딧 2개 지급**
- YouTube Shorts 설명란(Description)과 pinned comment에 PayPal 결제 링크 직접 삽입
- 7일 내 첫 5건 이상 거래 생성 목표 → 실제 결제 흐름(Payment Flow) 테스트 및 신뢰도 확보
