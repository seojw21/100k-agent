# 📦 서비스 등록 자료 패키지 (dumpany)

## 1. 기본 정보
- **서비스명**: dumpany
- **타입**: 오픈소스 CLI 도구 / Python 패키지
- **GitHub URL**: https://github.com/peerswick/dumpany
- **랜딩페이지**: `./src/landing/uk_pdf.html` (Dark Theme, 반응형)
- **라이선스**: MIT (가정/오픈소스 기준)

## 2. 서비스 설명 (한 줄 / 상세)
- **한 줄**: UK Companies House 데이터의 PDF 문서를 CLI로 대량 다운로드하는 오픈소스 도구
- **상세**: pip 한 줄 설치로 특정 회사의 모든 공시 문서(PDF)를 자동 다운로드합니다. Companies House API와 연동되며, AI 분석(NotebookLM 등) 및 로컬 브라우징을 위한 데이터 파이프라인으로 활용 가능합니다.

## 3. 핵심 기능 (Features)
1. **대량 PDF 다운로드**: 회사 등록번호 입력 시 모든 관련 문서 일괄 수집
2. **API 연동 안정화**: Companies House 공식 API 기반, Rate Limit(600/min) 자동 제어
3. **AI/OSINT 파이프라인**: 다운로드된 PDF를 NotebookLM 또는 로컬 DB에 바로 연결 가능
4. **오프라인 브라우징**: 인터넷 연결 없이도 로컬 저장된 문서 검색 및 분석 지원

## 4. 타겟 사용자
- UK 기업 데이터 기반 OSINT 연구자
- Due Diligence/Compliance 담당자
- Python 기반 데이터 파이프라인 개발자

## 5. 설치 및 사용 가이드
```bash
pip install dumpany
dumpany.py --company-number 12345678
```
⚠️ **주의**: Companies House API는 분당 600회 제한이 있습니다. 대량 다운로드 시 5분 간격으로 실행하세요.
