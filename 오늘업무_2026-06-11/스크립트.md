## 2. 📝 블로그 게시글 (Professional Tone)

**제목:** [OSINT] 영국 기업 데이터의 60%가 PDF인 이유와 `dumpany` 해결책
**카테고리:** Data Science / OSINT / Python Tool

**본문:**
영국 기업 등록소(Companies House)에는 무려 **500만 개**에 달하는 기업의 정보가 공개되어 있습니다. 하지만 데이터 분석가들에게 이는 골칫거리입니다. 왜냐하면 전체 데이터의 약 **60%가 PDF 파일**로 되어 있어, 구조화된 데이터(DB)처럼 바로 활용하기 어렵기 때문입니다.

이 문제를 해결하기 위해 개발된 오픈소스 도구가 바로 **`dumpany`**입니다.

### 🛠️ dumpany란?
GitHub에서 별 7개를 받은 이 도구는 Python으로 작성되었으며, 다음과 같은 기능을 제공합니다:
1.  **대량 다운로드:** 특정 기업 번호를 입력하면 관련 PDF를 자동으로 다운로드합니다.
2.  **API 연동:** 분당 600회(Requests/5min)의 API 제한 내에서 효율적으로 데이터를 수집합니다.
3.  **AI 분석 연계:** 다운로드한 PDF 데이터를 Google NotebookLM 등의 AI 도구에 바로 투입할 수 있습니다.

### 💻 설치 및 사용법
터미널에서 다음 명령어만 입력하면 됩니다.
```bash
pip install dumpany
```
이제 복잡한 웹 스크래핑 없이도 영국 기업 정보를 손쉽게 확보하세요.
