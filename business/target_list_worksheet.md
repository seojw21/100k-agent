# RateParse — 타겟 브로커 수집 워크시트 (첫 10곳)

> 정직한 전제: 웹 검색 상위 = SEO 잘하는 중대형 회사(우리 핏 아님). 진짜 초소형
> 브로커(1~10인)는 검색에 안 뜬다. 아래 절차로 직접 필터링해야 한다.
> 목표: 오늘 30~45분에 10곳 수집 → 이름·URL·연락처만 채우면 내가 이메일 맞춤 작성.

---

## 방법 A — LinkedIn (가장 정확, 추천)

1. LinkedIn 검색창에 `freight broker` 입력 → People 탭
2. 필터: **Current company** 규모 작게 짐작(회사 페이지 들어가 "1-10 employees"/"11-50" 확인)
3. 타이틀에 **Owner / Founder / President** 있는 소규모 회사 사람 = 결정권자
4. 회사 페이지 → 웹사이트 링크 → **Contact 페이지에서 이메일** 확보
5. 핏 신호: family-owned, boutique, 직원 수 적음, "no. 1 point of contact" 강조, 데모/엔터프라이즈 언어 없음

## 방법 B — FMCSA SAFER (공식 등록부)

1. https://safer.fmcsa.dot.gov/keywordx.asp?searchstring=*BROKER* — 회사명에 BROKER 포함 업체 목록
2. 관심 회사 클릭 → 소재지·MC번호 확인 → 회사명 구글 → 웹사이트 → Contact
3. 대형(수백 대 트럭 제휴)·이미 TMS 완비 = 스킵. 소박한 사이트 = 타겟.

## 방법 C — Google 지역 검색

1. `freight brokerage [도시명]` (예: freight brokerage Tulsa, freight brokerage Boise)
2. 대도시(시카고·애틀랜타)보다 **중소도시**가 초소형 브로커 밀집 + 경쟁 덜함
3. 소박한 웹사이트 + Contact 이메일 있는 곳 = 타겟

---

## ⚠️ 이메일 확보 규칙

- **웹사이트 Contact 페이지의 공개 이메일**(info@, ops@, 담당자@)만 사용
- 이메일 지어내기·추측(firstname@company.com 찍기) 금지 → 반송되면 도메인 평판 손상
- 구매한 리스트·스크래핑 대량수집 금지
- LinkedIn이면 우선 사이트 이메일, 없으면 LinkedIn 메시지(단 커넥션 필요)
