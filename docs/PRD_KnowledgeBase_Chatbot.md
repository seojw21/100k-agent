
# [PRD] B2B 사내 지식 베이스 챗봇 (MVP 버전)

## 1. 프로젝트 개요
- **목적:** 기업 내부의 파편화된 정보(노션, 슬랙, 매뉴얼 등)를 통합하여 직원이 질문하면 즉시 정확한 답변과 출처를 제공하는 AI 비서 구축.
- **핵심 가치:** "정보 탐색 시간 단축" 및 "반복적인 사내 문의 대응 자동화".

## 2. 타겟 고객 (Initial Target)
1.  **IT 에이전시/스타트업:** 팀 규모가 커지면서 온보딩 교육 및 내부 정보 공유에 리소스 소모가 큰 조직.
2.  **전문직 서비스(법무, 세무):** 규정이나 매뉴얼이 복잡하여 정확한 정보 확인이 필수적인 조직.

## 3. 핵심 기능 (MVP Scope)
- **멀티 소스 데이터 통합:** Notion API 및 PDF/Docx 파일 업로드 지원.
- **RAG 기반 지식 검색:** 단순 키워드 매칭이 아닌 의미론적(Semantic) 검색을 통한 답변 생성.
- **출처 표시(Source Citation):** 답변의 근거가 되는 문서의 링크나 페이지를 함께 제공 (신뢰도 확보).
- **슬랙/카카오톡 연동:** 별도 앱 접속 없이 기존 협업 툴 내에서 챗봇과 대화.

## 4. 수익 모델 (Monetization)
- **Setup Fee:** 초기 데이터 인덱싱 및 맞춤형 프롬프트 엔지니어링 컨설팅 비용.
- **Monthly Subscription:** 사용자 수(Seat) 기반 또는 월간 처리 데이터량에 따른 구독료.
- **Premium Tier:** 고도화된 보안 설정 및 전용 서버 구축 옵션.

## 5. 성공 지표 (KPI)**
- 도입 후 사내 정보 관련 질문 응대 시간 50% 이상 감소.
- 신규 입사자 온보딩 기간 단축.
- 높은 사용자 만족도 및 재계약률.
