# 🚀 100k Agent - Business Intelligence System

안녕하세요! 당신의 사업화를 돕는 **100k 에이전트**입니다.
매일 전 세계의 비즈니스 아이템과 아이디어를 발굴하고, 레딧 핵심통증 3,000개 이상의 DB를 세컨드 브레인으로 관리합니다.

## 📂 폴더 구조
- `memory/`: 매일 발굴한 아이디어 리포트가 저장되는 공간입니다.
- `knowledge/`: 정제된 지식 베이스가 보관됩니다.
  - `md_brain/`: Connect AI Lab 지식 네트워크 시각화용 Markdown 파일이 보관됩니다.
- `agent.py`: 자동화 검색 및 요약을 담당하는 스크립트입니다.
- `build_knowledge.py`: 레딧 데이터(TSV)를 정제하고 999개 MD 지식을 재생성하는 스크립트입니다.

## 🧠 세컨드 브레인(지식 네트워크) 복구 및 갱신 방법
이전 지식을 모두 복구하고 115개의 샘플 그래프에서 벗어나 실제 3,000개 이상의 지식 DB를 시각화하려면 다음 단계를 진행해 주세요.

1. **VS Code 터미널**을 엽니다 (`Ctrl + ~`).
2. 아래 명령어를 실행하여 3,000개 이상의 아이디어 병합 및 시각화용 999개 Markdown 파일을 생성합니다.
   ```bash
   python d:\100k\build_knowledge.py
   ```
3. 생성이 완료되면 `knowledge/md_brain/` 폴더에 마크다운 파일들이 채워집니다.
4. VS Code 명령 팔레트(`Ctrl + Shift + P`)에서 **Show Brain Topology**를 실행하거나, 사이드바를 확인해 보세요!
   > **주의:** `connectAiLab.localBrainPath` 설정은 이미 `d:\100k\knowledge\md_brain`으로 자동 연동되도록 구성해 두었습니다.

## 🛠 미션 및 운영 방식
1. **매일 오전 8시 탐색**: 국내(한국) 및 해외(미국, 일본, 유럽 등)의 트렌드 사이트를 분석합니다.
2. **사업화 관점 분석**: 단순 뉴스가 아닌, '실제로 구현 가능한' 비즈니스 모델 위주로 정리합니다.
3. **메모리 축적**: 모든 데이터는 마크다운 형식으로 `memory` 폴더에 날짜별로 저장됩니다.
